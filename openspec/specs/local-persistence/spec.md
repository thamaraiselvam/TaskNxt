## Purpose

Guarantees that all application data (tabs, tasks, and settings) is stored exclusively on the local device, with no network transmission, accounts, cloud sync, or analytics, matching the original TodoNxt's privacy model.

## Requirements

### Requirement: Local-only data storage
All application data (tabs, lanes, tasks, settings) SHALL be persisted only to local on-device storage. The system SHALL NOT transmit this data to any network endpoint.

#### Scenario: No network calls for data operations
- **WHEN** the user creates, edits, completes, or deletes a task, tab, or setting
- **THEN** no network request is made as part of persisting that change

### Requirement: No account or sign-in required
The system SHALL NOT require account creation, sign-in, or any authentication to use any feature.

#### Scenario: Full functionality without sign-in
- **WHEN** the app is launched for the first time
- **THEN** the user can create tabs and tasks and use all features without being prompted to sign in or create an account

### Requirement: No analytics or telemetry
The system SHALL NOT collect or transmit usage analytics, crash reports, or telemetry to any third party.

#### Scenario: No telemetry libraries active
- **WHEN** the app is running
- **THEN** no analytics/telemetry network traffic is generated by the app

### Requirement: Data persists across restarts
All tabs, tasks (including completion state and countdown), and settings SHALL persist across app restarts and macOS reboots.

#### Scenario: Data survives app relaunch
- **WHEN** the user creates tasks and quits the app
- **AND** relaunches the app
- **THEN** all previously created tabs and tasks are present with their prior state (done/incomplete, lane, order)

### Requirement: No cloud sync
The system SHALL NOT sync data across multiple devices. Data created on one Mac SHALL remain local to that Mac only.

#### Scenario: No sync mechanism present
- **WHEN** the same user runs the app on a second Mac
- **THEN** tasks created on the first Mac do not appear on the second Mac
